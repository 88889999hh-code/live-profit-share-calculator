# 直播利润与分红计算器

移动端优先的静态网页计算器，所有经营数据在浏览器本地处理，无账号、无付费API、无数据库。`index.html` 可独立使用，支持免费静态托管。

## 主要功能
- 输入支付GMV、售价、进货成本、按金额计退款率、投流、平台扣费、双员工保底工资等
- 高级设置：首程物流、退货前取消订单占比、退货可重新销售率、开票加价、房租水电、用工成本、税费预留、以前月份待弥补亏损
- 实时计算净销售额、广告费用、分红前经营利润、保本GMV与老板/主播/中控总收入
- 分红比例默认50%/25%/25%，可修改
- 手机浏览器原生分享、参数分享链接、打印为PDF

## 计算口径和限制
- 退款率为退款金额 / 支付GMV，单均价用以推导单数。
- 假设所有订单同价，退回且可再售的货品保留为存货，不重复核算为损耗。
- 税率为可调整预算，不自动判断申报周期、免税资格或法定所得税税率。
- 分红池 = max(0, 本月经营利润 − 历史待弥补亏损)。负利润不分红，保底仍计入固定开支。
- 分享链接会包含当前参数；网页不将表单提交到服务器。

使用说明：直接用浏览器打开 `index.html`，或把本文件上传到任意静态网页托管平台。
